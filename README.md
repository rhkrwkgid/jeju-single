# 제주 1인 세대 살핌 보고서

매달 "이달 먼저 살펴볼 동"을 알려 주는 월간 보고서입니다. GitHub Actions가 매일 새벽 한 번 공공데이터포털을 확인해, 새 달 자료가 나오면

1. `data/single.json`에 그달 자료를 쌓고
2. `scripts/report.py`가 기준(80세 이상 증가, 청년 급증, 80세 이상 비중, 1년 증가)을 계산해 보고서를 만들고(외부 AI 없음, 문장 틀)
3. 화면(index.html)과 `reports/연월.md`에 저장한 뒤
4. 같은 보고서를 저장소 **Issues**에 "월간보고서" 라벨로 올립니다. 저장소를 Watch 해 두면 담당자 메일로 옵니다.

- 자료: 행정안전부_법정동별(행정동 통반단위) 성/연령별 주민등록 1인세대수 (공공데이터포털 오픈API)
- 기준: 주민등록 월말 기준, 한 달에 한 번 바뀜. 실시간 자료가 아닙니다.
- 지금 들어 있는 `data/single.json`은 **교육용 가상 데이터**입니다. 첫 실행에서 실제 자료로 바뀝니다.

## 올리는 순서

1. 새 공개 저장소를 만들고 `index.html`, `data/`, `reports/`, `scripts/collect.py`, `scripts/report.py`, `README.md`를 올립니다. 폴더째 끌어 놓으면 폴더 구조가 그대로 올라갑니다.
2. Settings > Secrets and variables > Actions > New repository secret. 이름 `PUBLIC_API_KEY`, 값은 공공데이터포털 인증키(Decoding).
3. Settings > Actions > General 맨 아래 Workflow permissions를 Read and write로 바꿉니다.
4. Actions 탭 > set up a workflow yourself, `workflow/collect.yml` 내용을 붙여 넣고 Commit. `.github/workflows/collect.yml`이 만들어집니다.
5. Actions 탭 > 1인 세대 월간 보고서 > Run workflow. 초록 체크가 뜨고 Issues에 "○년 ○월 말 1인 세대 살핌 보고서"가 올라오면 성공입니다.
6. Settings > Pages에서 main, / (root)로 켜고 1~2분 뒤 `https://아이디.github.io/저장소이름/`을 엽니다.

## 처음 한 번 맞출 것

`scripts/collect.py` 맨 위 `CONFIG`의 요청주소, 요청변수, 출력결과 이름을 공공데이터포털 상세 페이지 표대로 고칩니다. "확인 필요"라고 적힌 곳입니다.

## 기준 바꾸기

`scripts/report.py` 맨 위 `RULES`의 숫자만 바꿉니다. 화면과 보고서의 기준 설명은 이 숫자를 따라 자동으로 바뀝니다.

| 기준 | 기본값 |
| --- | --- |
| 80세 이상 한 달 증가 | 지난달보다 10세대 이상 |
| 청년 급증 | 지난달보다 8% 이상이면서 20세대 이상 |
| 80세 이상 비중 높음 | 1인 세대 중 80세 이상 20% 이상, 지난달보다 0.5%p 이상 상승 |
| 80세 이상 1년 증가 | 작년 같은 달보다 8% 이상 |
| 이달 먼저 살펴볼 동 | 걸린 기준이 많은 순으로 3곳 |

## 알고 쓸 점

| 항목 | 내용 |
| --- | --- |
| 비율 | 전체 세대수가 없어 세대 수만 비교합니다. 큰 동이 위에 오기 쉽습니다. |
| 기준 차이 | 주민등록 1인 세대는 통계청 1인 가구와 기준이 다릅니다. |
| 작은 칸 | 통 · 반 값은 읍면동으로 합쳐서만 보여 줍니다. |
| 쓰임 | 살필 순서의 참고입니다. 위기 가구를 찾아내는 근거가 아닙니다. |
| 키 | Secrets에만 둡니다. 결과 파일과 로그에서는 *** 로 가립니다. |
| 멈춤 | 공개 저장소에 60일 동안 변화가 없으면 예약 실행이 꺼집니다. 한 달에 한 번은 자료가 바뀌므로 보통은 이어집니다. |

## 막힐 때

| 증상 | 해결 |
| --- | --- |
| 저장 단계에서 403 | Workflow permissions를 Read and write로 |
| Issue가 안 올라옴 | Settings > General > Features에서 Issues 켜기. 이미 보고서를 만든 달이면 다시 올리지 않음 |
| 로그에 "결과 코드 30" | 그 API 활용신청 확인, 승인 뒤 1시간쯤 기다림 |
| 로그에 "아직 자료가 없습니다" | 지난달 자료가 아직 안 나옴. 다음 날 다시 확인됨 |
| 내 PC에서 두 번 눌러 열면 예시만 보임 | 정상. 내 PC에서는 HTML 안의 가상 예시를 씁니다. Pages 주소로 여세요 |

교육용 시연 저장소입니다. 업무에 쓸지와 공개 범위는 기관 보안 담당과 정합니다.
